# Typography

Font families, weights, and text styles using the active light or dark theme. The examples below render the Angular
typography directives directly, so the design reference and implementation stay together.

## Angular usage

Import `HlmTypographyImports` from `@nuclia/ui-spartan/typography` and apply the directives to native HTML elements.
Use **Show code** on each example for the implementation.

Headings use `--font-display`; body text uses `--font-sans`; inline code uses `--font-mono`.
Colors and borders follow the active theme.

## Headings

Use `hlmH1` for the page title, `hlmH2` for major sections, `hlmH3` for subsections, and `hlmH4` for supporting headings.
Keep a single `<h1>` per page and do not skip heading levels.

<Canvas of={TypographyStories.Headings} />

## Body and supporting text

Use `hlmP` for body copy, `hlmLead` for page introductions, `hlmLarge` for emphasised statements,
`hlmSmall` for captions, and `hlmMuted` for secondary information.

<Canvas of={TypographyStories.BodyText} />

## Rich content

Choose native elements for their meaning. Use `hlmBlockquote` for quoted passages, `hlmUl` for related items,
and `hlmCode` for inline identifiers.
